# Phase-6 PinAI Luna post-hoc statistics

This package contains six-arm Phase-6 model results, separate raw/audit/intervention ranking metrics, descriptive paired comparisons, provider token totals, and annotations explicitly named `人工+大模型辅助标注（模拟人工）`. The annotations are simulated by Luna and are not human labels. Gold is read locally only for post-hoc scoring and is not included in the package.
